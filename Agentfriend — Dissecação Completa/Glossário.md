# Glossário

- Turn: iteração do loop entre mensagens de assistant/tool e próximo estado.
- tool_use: bloco solicitado pelo modelo com nome da tool e input.
- tool_result: retorno da tool mapeado para o protocolo do modelo.
- Boundary messages: mensagens sintéticas para demarcar compactações.
- RO/RW: Read‑Only / Read‑Write (mutável) em ferramentas.
- StructuredIO: protocolo NDJSON para controle/stream/eventos com ordenação/dedup.
- HybridTransport: WS (leitura) + POST batelado (escrita).
